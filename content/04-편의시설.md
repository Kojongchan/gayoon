# 04. 편의시설 · 서비스

> 홈페이지 "이용 혜택" 섹션 재료. 공식 안내 문구 기준으로 정리.
> 헤드라인: **"멤버십 회원에게 드리는 이용 혜택"**

## ✅ 쇼핑몰 특화 (강조 포인트 ●)
- 📦 **택배 집하장** ● — 집하/발송 가능
- 📷 **포토 스튜디오** ● — 조명·배경지 구비, 제품/의류 촬영

## ✅ 멤버십 기본 혜택 (전체)
| 혜택 | 혜택 |
|------|------|
| ☕ 원두커피 | 🌐 빠른 인터넷 |
| 🕛 24/7 사무실 이용 | ☕ 웰컴 머그컵 |
| 🖨️ 복합기 | 🧑‍🤝‍🧑 회의실 |
| ❄️ 24/7 냉난방 | 🛋️ 공용 라운지 |
| 💧 정수기 | 🪑 사무가구 |

## ✅ 보안
- 🔒 **지문인식 출입** · 🚪 **룸별 도어락(번호+카드)** · 📹 **CCTV**

## ✅ 비용 정책
- 💸 **월 이용료 외 추가 비용 없음** — 위 혜택 전부 포함

## 홈페이지 카피 포인트
> "월 이용료 하나로 끝 — 커피·인터넷·회의실·복합기·라운지까지 전부 포함."
> **쇼핑몰 사장님이라면**: 택배 집하장 + 포토스튜디오로 *촬영부터 발송까지 한곳에서*.
> 기능 나열보다 **"추가 지출이 없다 + 쇼핑몰에 최적"** 을 강조.
