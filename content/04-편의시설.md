# 04. 편의시설 · 서비스

> 홈페이지 "혜택/편의시설" 섹션 재료. 아이콘 + 한 줄로 보여줄 항목들입니다.

## ✅ 무료 제공 (공개 자료 확인)
- ☕ **원두커피 무한 제공**
- 🗓️ **회의실 무료 이용** (8인실 보유)
- 🖨️ **공용 PC · 복합기(프린터/복사/스캔) 무료**
- 📷 **포토 스튜디오 무료 이용**
- 📦 **택배 집하장 완비 + 저렴한 택배 발송**
- ❄️ **냉난방 완비**
- 🕛 **24시간 / 365일 자유 이용**
- 💸 **월 이용료 외 추가 비용 없음**

## ✅ 보안
- 🔒 **지문인식 출입**
- 🚪 **룸별 도어락**
- 📹 **CCTV 상시 운영**

## ⚠️ 확인하면 좋은 추가 편의 (있으면 강점)
- [ ] 냉장고 / 정수기 / 전자레인지 등 탕비실
- [ ] 무선 인터넷(전용/공용) 속도
- [ ] 흡연구역 / 주차 가능 여부
- [ ] 사업자등록(비상주/주소지) 가능 여부
- [ ] 우편물 수령·보관 서비스
- [ ] 사물함(개인 보관함)
- [ ] 라커/샤워실 등

## 홈페이지 카피 포인트
> "월 이용료 하나로 끝 — 커피·회의실·프린터·택배·스튜디오까지 전부 무료."
> 기능 나열이 아니라 **"추가 지출이 없다"는 안심**을 강조 (Step 0 레퍼런스 원칙 5번).
