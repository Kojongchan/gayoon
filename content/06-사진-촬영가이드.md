# 06. 사진 수집 · 촬영 가이드

> 📷 **사진은 전환율에 가장 큰 영향을 주는 요소**입니다 (Step 0 레퍼런스 3번).
> 스톡 이미지 말고 **실제 천호역점 사진**을 사용합니다.
> 전문 촬영이 아니어도 좋습니다 — 아래 가이드대로 스마트폰으로 찍어 보내주세요.

## 보내주실 위치 / 파일 규칙
- 위치: `assets/images/` 폴더
- 파일명(영문 소문자, 띄어쓰기 대신 `-`):
  - `hero.jpg` — 첫 화면용 대표 사진(가장 넓고 분위기 좋은 컷)
  - `room-1p-01.jpg` — 1인실
  - `room-team-01.jpg` — 다인실/팀룸
  - `meeting-01.jpg` — 회의실
  - `lounge-01.jpg` — 라운지
  - `studio-01.jpg` — 포토스튜디오
  - `delivery-01.jpg` — 택배존
  - `entrance-01.jpg` — 입구/외관(간판 보이게)
  - `amenity-coffee.jpg`, `amenity-printer.jpg` 등 — 편의시설 디테일

## 꼭 필요한 필수 컷 (최소 세트)
- [ ] 외관/입구 (간판 + 1층 보이게) 1장
- [ ] 1인실 1장
- [ ] 다인실(팀룸) 1장
- [ ] 회의실 1장
- [ ] 라운지/공용공간 1장
- [ ] 포토스튜디오 1장
- [ ] 커피머신·복합기 등 편의시설 디테일 2~3장

## 잘 나오는 촬영 팁
1. **가로(landscape)로** 찍기 — 웹은 가로가 기본.
2. **불 다 켜고, 낮에** 자연광 함께. 어두우면 칙칙해 보입니다.
3. **정리 후** 촬영 — 책상 위 잡동사니/쓰레기통 치우기.
4. 사람이 살짝 일하는 **연출 컷 1~2장** 있으면 분위기↑ (얼굴 노출은 동의받기).
5. 같은 공간을 **2~3가지 각도**로 — 고를 수 있게.
6. 너무 가까이 X — 공간 전체가 보이게 **한 발 물러서서**.
7. 해상도: 스마트폰 기본 화질이면 충분 (가로 1600px 이상 권장).

## 사진이 없거나 부족할 때 임시 대안
- 당장은 **회색 플레이스홀더 박스 + "사진 준비 중"** 으로 자리만 잡아두고,
  Step 3 배포 후 사진이 오면 교체합니다. (사이트 오픈은 막지 않음)
- 너무 급하면 슈가맨워크 공식/플랫폼(쉐어잇·당근)에 올라간 천호역점 사진을
  **사장님 본인 자료일 경우에만** 사용 (저작권 확인 필요 ⚠️).

## 추가로 받으면 좋은 것
- [ ] 브랜드 로고 이미지 (`logo.png`, 배경 투명 PNG면 베스트)
- [ ] 입주사 로고 / 후기 캡처 (신뢰 요소용, 동의 필요)
