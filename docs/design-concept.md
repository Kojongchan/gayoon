# 디자인 컨셉 — 슈가맨워크 서울 천호역점

> Step 1 산출물 ①
> 키워드: **심플(Simple) · 트렌디(Trendy) · 친근한 프로페셔널**
> 이 문서는 색·폰트·톤·무드를 "확정"합니다. Step 4 스타일링은 이 문서를 그대로 따릅니다.

## 1. 레퍼런스 분석 (우수 사례에서 가져올 것)

국내외 대표 공유오피스/코워킹 사이트를 분석해 **우리가 차용할 패턴**과 **차별화 포인트**를 정리했습니다.

| 레퍼런스 | 디자인 인상 | 잘한 점 (가져올 것) |
|---|---|---|
| **패스트파이브 (FastFive)** | 흰 배경 + **보라(퍼플) 포인트** 1컬러, 굵은 한글 산세리프, 큰 사진 | 1포인트 컬러로 브랜드를 각인 / "무료 상담" CTA를 항상 노출 / 지점·상품을 의도별로 분기 |
| **스파크플러스 (SparkPlus)** | 밝고 깔끔, **그린/민트 계열 포인트**, 실제 공간 사진 중심 | 공간 사진의 퀄리티로 신뢰를 줌 / 요금·공간을 카드로 명확히 / 여백이 넉넉 |
| **위워크 (WeWork)** | **블랙&화이트 + 강한 타이포**, 채도 높은 사진 | 큰 헤드라인 한 줄로 메시지 전달 / 커뮤니티·사람 중심 카피 / 강한 시각적 위계 |

> 경쟁사 정확한 브랜드 컬러값은 비공개라 위 인상은 "관찰된 패턴" 수준입니다. **핵심은 컬러값이 아니라 구조**: ① 1포인트 컬러 ② 큰 타이포 ③ 실제 사진 ④ 명확한 가격 ⑤ 항상 보이는 CTA.

**최신 트렌드(2026)에서 가져올 것**
- 2~3톤으로 줄인 **미니멀 팔레트**, 색이 아니라 **여백으로 구조**를 만든다.
- **굵고 큰 타이포 + 1포인트 컬러 팝**으로 심플하면서 지루하지 않게.
- 따뜻한 톤의 오프화이트로 "AI처럼 매끈한" 느낌을 덜고 **사람 냄새**를 더한다.

**우리의 차별화 한 줄**
> 경쟁사가 퍼플(패파)·그린(스플)·블랙(위워크)을 쓰니, 우리는 브랜드명 **"슈가(Sugar)"에서 온 따뜻한 허니 앰버**를 1포인트로. → 천호 상권에서 **밝고 친근하고 트렌디한** 동네 거점 이미지.

## 2. 톤앤매너 (확정)

**모던 미니멀 + 따뜻한 1포인트 + 친근한 말투**

- **깔끔함**: 넉넉한 여백, 정돈된 그리드, 2~3색만 사용
- **트렌디함**: 큰 헤드라인, 라운드 코너, 부드러운 그림자, 1포인트 컬러 팝
- **친근함**: "함께 일하기 좋은 동네 오피스" — 기능 나열이 아니라 사람 말투 카피
- **신뢰감**: 실제 공간 사진, 명확한 가격, 후기/숫자

말투 예시
- ❌ "프리미엄 워크스페이스 솔루션 제공"
- ✅ "천호역 1분, 짐만 들고 오면 바로 일할 수 있어요."

## 3. 컬러 팔레트 (확정)

심플 원칙: **1 포인트 컬러 + 잉크(검정) + 뉴트럴(회색·오프화이트)**. 색은 적게, 여백은 넉넉히.

### 메인 / 포인트
| 역할 | 이름 | HEX | 용도 |
|---|---|---|---|
| **Primary (브랜드 포인트)** | Honey Amber | `#F5A524` | CTA 버튼, 강조 텍스트/숫자, 링크 hover, 아이콘 포인트 |
| **Primary Dark** | Amber Deep | `#D7860B` | 버튼 hover/active, 포인트 위 텍스트 대비 |
| **Ink (기본 텍스트/딥 배경)** | Warm Ink | `#1B1A17` | 본문·제목 텍스트, 푸터 배경 |

### 뉴트럴 (구조용)
| 역할 | 이름 | HEX | 용도 |
|---|---|---|---|
| Base 배경 | Warm White | `#FCFBF8` | 페이지 기본 배경 (따뜻한 오프화이트) |
| Surface | Pure White | `#FFFFFF` | 카드·패널 배경 |
| Text Sub | Gray 600 | `#6B6862` | 보조 설명 텍스트 |
| Border/Line | Gray 200 | `#E8E5DE` | 구분선, 카드 테두리 |
| Soft Tint | Amber Tint | `#FDF3E0` | 강조 섹션 배경(은은한 앰버 톤) |

### 시스템 컬러 (상태 표시)
| 역할 | HEX |
|---|---|
| 성공/확인 | `#2E7D5B` |
| 경고/주의 | `#D9534F` |

### 사용 비율 가이드 (60-30-10)
- **60%** Warm White / White (배경·여백)
- **30%** Warm Ink / Gray (텍스트·구조)
- **10%** Honey Amber (CTA·포인트만 — 절대 남발하지 않기)

> 🔁 **대안 포인트(원하면 교체):** 더 발랄·트렌디하게 가고 싶으면 코랄 `#FF6B4A`, 더 차분하게 가고 싶으면 딥 티얼 `#1F6F5C`. 구조는 동일하고 Primary 한 줄만 교체하면 됩니다. **추천은 Honey Amber** (브랜드명 "슈가"와 직결 + 경쟁사와 차별).

## 4. 타이포그래피 (확정)

**원칙:** 폰트는 1패밀리로 통일하고 **굵기(weight) 대비**로 위계를 만든다 → 심플 + 빠른 로딩.

### 기본 폰트: **Pretendard**
- 이유: 가장 트렌디·범용적인 한글 웹폰트, 무료(OFL), CDN 제공, 숫자·영문도 깔끔 → GitHub Pages에 바로 적용
- CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css`

### (선택) 헤드라인 디스플레이: **Gmarket Sans Bold**
- 히어로 대형 헤드라인 1곳에만 포인트로 사용 가능(개성↑). 부담되면 Pretendard ExtraBold로 통일해도 충분.

### 타입 스케일
| 용도 | 폰트/굵기 | 크기(데스크탑) | 비고 |
|---|---|---|---|
| Hero 헤드라인 | Pretendard ExtraBold 800 | 48–64px | 모바일 32–40px |
| 섹션 제목 (H2) | Pretendard Bold 700 | 32–40px | |
| 소제목 (H3) | Pretendard SemiBold 600 | 22–26px | |
| 본문 | Pretendard Regular 400 | 16–18px | 행간 1.6 |
| 보조/캡션 | Pretendard Regular 400 | 13–14px | Gray 600 |
| 가격 숫자 | Pretendard Bold 700 | 28–36px | 가독성 강조 |

- 자간: 한글 제목 -0.01em~ -0.02em(타이트하게), 본문 기본
- 한 줄 길이: 본문 최대 약 38~42자

## 5. UI 스타일 토큰 (Step 4에서 그대로 사용)

| 요소 | 값 |
|---|---|
| 모서리 라운드 | 버튼/카드 12–16px, 이미지 16–20px (트렌디한 둥근 코너) |
| 그림자 | 부드럽게: `0 8px 24px rgba(27,26,23,0.08)` |
| 섹션 상하 여백 | 데스크탑 96–120px, 모바일 56–72px |
| 컨테이너 최대폭 | 1120–1200px, 좌우 패딩 20–24px |
| 기본 버튼(Primary) | 배경 Honey Amber, 텍스트 Warm Ink, 라운드 12px, hover 시 Amber Deep |
| 보조 버튼(Ghost) | 투명 배경 + Ink 1px 보더, hover 시 연한 틴트 |
| 전환(transition) | 150–200ms ease, hover 살짝 떠오르는 효과 |

**CTA 문구 후보**: `무료 투어 신청` / `상담 받기` / `요금 보기` / `전화 문의` / `카카오톡 문의`

## 6. 무드보드 (말로 그리는 그림)

- 첫인상: **밝은 오프화이트 배경**에 큰 검정 헤드라인 한 줄, 그 옆/아래 **허니 앰버 버튼** 하나.
- 메인 비주얼: 천호역점 **실제 라운지/책상 사진**(따뜻한 자연광), 둥근 모서리.
- 전체적으로 **여백이 많고**, 색은 거의 흑백인데 **버튼·숫자·아이콘에만 앰버**가 톡 — "심플한데 따뜻하고 트렌디".
- 레퍼런스 분위기 키워드: *토스(군더더기 없는 깔끔함) + 무신사스러운 큰 타이포 + 동네 카페 같은 따뜻함*.

## 7. 접근성 체크 (지킬 것)
- 본문 텍스트는 Warm Ink(`#1B1A17`) on Warm White → 대비 충분(AA 통과)
- 앰버 버튼 위 텍스트는 **검정(Warm Ink)** 사용(흰색은 대비 부족). 
- 포인트 컬러만으로 정보 구분하지 않기(아이콘·텍스트 병행)
- 폰트 최소 본문 16px, 터치 타깃 44px 이상
