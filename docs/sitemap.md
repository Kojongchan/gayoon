# 사이트맵 (정보구조) — 슈가맨워크 서울 천호역점

> Step 1 산출물 ②
> 어떤 페이지/섹션이, 어떤 순서로, 어떤 목적으로 들어가는지 "확정"합니다.
> 디자인 톤/색/폰트는 같은 폴더의 [`design-concept.md`](./design-concept.md) 참고.

---

## 1. 구조 전략 (확정)

**원페이지(One-page) 스크롤 중심 + 필요한 하위 페이지 점진 추가.**

- 이유: 공유오피스 방문자는 "여기서 일할 수 있나? 얼마지? 어디지? 어떻게 문의하지?"를 **한 화면 스크롤로 빠르게** 확인하고 싶어함 → 심플·트렌디 컨셉과도 일치.
- **MVP(Step 3):** `index.html` 한 장에 핵심 섹션을 세로로 쌓고, 상단 메뉴는 **앵커 이동**(`#space`, `#price` …).
- **확장(Step 6~8):** 갤러리/후기/공지·FAQ/결제는 분량이 커지면 별도 페이지로 분리.

---

## 2. 글로벌 내비게이션 (상단 고정 헤더)

```
[ 🍯 슈가맨워크 천호역점 ]   공간소개  요금안내  편의시설  오시는길  후기   [📞 전화] [무료 투어 신청 ▸]
```

- 항상 화면 상단 고정(sticky), 스크롤 시 살짝 그림자.
- 우측 끝 **「무료 투어 신청」 = Primary CTA(앰버 버튼)**, 항상 노출.
- 모바일: 햄버거 메뉴 + 하단 고정 바(전화 / 카톡 / 투어신청).

| 메뉴 라벨 | 이동(앵커) | 목적 |
|---|---|---|
| 공간소개 | `#space` | 1인실/다인실/회의실/라운지 등 분기 |
| 요금안내 | `#price` | 가격 명확 공개 |
| 편의시설 | `#amenities` | 라운지·프린터·택배 등 혜택 |
| 오시는길 | `#location` | 천호역 출구·도보 |
| 후기 | `#review` | 신뢰 요소 |
| 전화/투어신청 | `#contact` | 전환(문의) |

---

## 3. 메인 페이지 섹션 구성 (위→아래 순서, 확정)

각 섹션의 목적과 해당 로드맵 Step·핵심목표(①문의 ②브랜드/공간 ③편의정보 ④결제)를 표기.

| # | 섹션 | 한 줄 목적 | 우선 Step | 목표 |
|---|---|---|---|---|
| 0 | **헤더/내비** | 항상 보이는 메뉴 + CTA | 3 | ① |
| 1 | **Hero(첫 화면)** | 3초 안에 "천호역 여기서 일할 수 있다" 전달 | 3 | ②① |
| 2 | **핵심 강점** | 왜 좋은지 3~4개 카드 | 3 | ② |
| 3 | **공간 소개(Space)** | 공간 종류를 카드로 분기 | 3 | ② |
| 4 | **요금 안내(Pricing)** | 요금제 표로 명확 공개 | 3 | ②④ |
| 5 | **편의시설(Amenities)** | 입주 시 혜택·편의 | 4 | ③ |
| 6 | **갤러리(Gallery)** | 실제 공간 분위기 사진 | 6 | ② |
| 7 | **후기/입주사(Trust)** | 후기·로고·숫자로 안심 | 6 | ② |
| 8 | **오시는 길(Location)** | 천호역 출구·도보·지도 | 5 | ① |
| 9 | **FAQ** | 자주 묻는 질문 | 7 | ③ |
| 10 | **문의/투어(Contact)** | 폼·전화·카톡으로 전환 | 5 | ① |
| 11 | **푸터(Footer)** | 연락처·운영시간·사업자정보 | 3 | ③ |

> MVP(Step 3)에서 먼저 들어가는 섹션: **0,1,2,3,4,8(간단),10(간단),11**. 나머지는 해당 Step에서 채움(빈 자리 placeholder로 골격만).

## 4. 섹션별 와이어프레임 (레이아웃 스케치)

### 1) Hero — 첫 화면
```
┌─────────────────────────────────────────────┐
│ (헤더 고정)                                   │
│                                               │
│  천호역 1분, 짐만 들고 오면              [대표  │
│  바로 일할 수 있는 오피스                  공간 │
│  슈가맨워크 천호역점                       사진]│
│                                               │
│  [무료 투어 신청 ▸]  [요금 보기]              │
│  ⭐ 5호선·8호선 천호역 · 24시간 출입           │
└─────────────────────────────────────────────┘
```
- 좌: 큰 헤드라인(ExtraBold) + 한 줄 서브 + CTA 2개 + 신뢰 한 줄
- 우: 실제 공간 사진 1장(둥근 모서리). 모바일은 사진 위→텍스트 아래.

### 2) 핵심 강점 — 3~4 카드
```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ 🚉 역세권  │ │ 💰 합리적   │ │ 🕒 24시간  │ │ ☕ 라운지  │
│ 천호역 1분 │ │ 가격       │ │ 자유출입   │ │ ·무료음료  │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

### 3) 공간 소개 — 카드 그리드
```
[ 1인 전용실 ]  [ 2~4인실 ]  [ 다인 오피스 ]
[ 회의실 ]      [ 라운지 ]   [ 폰부스 ]
각 카드: 사진 + 이름 + 한줄설명 + "자세히/문의"
```

### 4) 요금 안내 — 요금제 표
```
┌─ 1인실 ─┐ ┌─ 다인실 ─┐ ┌─ 일일권 ─┐
│ 월 OO원 │ │ 월 OO원  │ │  OO원   │
│ ✓ 24시간 │ │ ✓ ...    │ │ ✓ ...   │
│ ✓ 라운지 │ │ ✓ ...    │ │         │
│ [문의]   │ │ [문의]   │ │[결제예정]│ ← ④는 Step8
└─────────┘ └─────────┘ └─────────┘
```

### 8) 오시는 길
```
┌──────────────┬───────────────────────┐
│ 카카오맵 임베드 │ 주소 / 천호역 O번 출구 │
│  (Step 5)     │ 도보 O분 / 주차 안내   │
│               │ [전화] [카카오톡]      │
└──────────────┴───────────────────────┘
```

### 10) 문의/투어 신청
```
┌─────────────────────────────────────┐
│  무료 투어 신청 / 상담                 │
│  [이름] [연락처]                      │
│  [관심 공간 ▾] [문의내용]             │
│  [신청 보내기 ▸]   또는 [📞전화][💬카톡]│
└─────────────────────────────────────┘
```
- 폼 전송: Formspree 등(서버리스) — Step 5에서 연결.

### 11) 푸터
```
슈가맨워크 천호역점 | 주소 | 전화 | 운영시간
사업자등록번호 | 이용약관 · 개인정보처리방침 | SNS
```
